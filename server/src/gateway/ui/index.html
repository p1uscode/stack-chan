キャラクター

名前・プロンプト・声を持つキャラクター。端末や Slack など「チャンネル」(端末・Slack等)から参照されます。1つのキャラクターを複数のチャンネルに宿らせられます。プロンプト空欄なら profile の中立な共通指示を使い、名前は自動で注入されます。保存で即反映(接続中は次ターンから)。

チャンネル

キャラクターが宿る先。タイプ別に管理します。stack-chan(物理ロボット)は接続で自動追加。今後 slack 等のタイプを増やせます。各チャンネルにキャラクター・声の上書き・ツール・追加プロンプトを設定。保存で即反映(接続中は次ターンから)。

全体(gateway.config.yaml)

common / characters / channels を含む全設定のJSON。GUI(キャラクター/チャンネル)で扱えない項目(common の endpoint・履歴パラメータ等)もここで直接編集できます。秘密(CF-Accessトークン)は含まれません。保存で即反映(既存接続は次ターンから)。

タイムライン(会話 + イベント)

会話とイベントを時系列で統合。日時・種別・誰・チャンネルで絞り込み。件数が多くてもサーバ側でページングします。
